# Iagon API


## Overview 

You can interact with the Iagon API via the [Postman link](https://api.docs.iagon.com/). A Personal Access Token is required to test auth-protected APIs. Please [log in](https://app.iagon.com) and go to your settings page to generate a Personal Access Token.
