# Iagon Terminology

<br/>
<br/>

This page defines the terminology that Iagon uses throughout this documentation.

<br/>

<!-- Please pay close attention to tags and hyperlinks to ensure easy navigation between terms, as well as easy term sharing via URL -->
<!-- Please capitalize products -->

| Term                        | Definition                                                                                                                                         |
|-----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| <a id="apps"></a>**App**(s) | Any application, script or task hosted with Iagon [Compute](#compute-product). |
| <a id="benchmark"></a>**Benchmark** | A multifaceted but brief resource stress test for [nodes](#nodes) to quantify the performance readings of the host system. |
| <a id="claim"></a>**Claim** | The action of moving [earnings](#earnings) out of the platform's smart contract and into one's own wallet. |
| <a id="commit-commitment-committed"></a>**Commit, Commitment, Committed** | Allocate a specific quantity of a host system's resources to the Iagon network. |
| <a id="compute-product"></a>**Compute** *(product)* | A stream of the Iagon network that hosts any tasks such as [app](#apps) hosting. Can include file hosting, but separate from [Storage](#storage-product). |
| <a id="cyclone"></a>**Cyclone** | A physical server purpose-built and configured by Iagon specifically to run a node in a plug-and-play manner. |
| <a id="cyclone-os"></a>**Cyclone OS** | A Linux operating system distribution that is pre-packaged with Iagon [Storage](#storage-product) and [Compute](#compute-product) [node](#nodes) as well as all of their dependencies. |
| <a id="delegators"></a>**Delegator**(s) | Person/party that offers their [IAG tokens](#iag-tokens) to a [node](#nodes) to increase its [stake](#stake) in exchange for an [earnings](#earnings) sharing agreement. |
| <a id="delegate-delegated-delegation"></a>**Delegate, Delegated, Delegation** | The act of contributing [IAG tokens](#iag-tokens) via Iagon's [Staking Platform](#staking-platform-product) to a [node](#nodes) to increase its total [stake](#stake) and thus [commit](#commit-commitment-committed) more resources. |
| <a id="delegation-request"></a>**Delegation Request** | A listing on Iagon's [Staking Platform](#staking-platform-product) requesting IAG Tokens from [delegators](#delegators) for a [node](#nodes) to increase its total [stake](#stake) and thus [commit](#commit-commitment-committed) more resources. |
| <a id="epoch"></a>**Epoch**(s)(ly) | A time period of 5 days, scheduled to Cardano's epochs. |
| <a id="earnings"></a>**Earnings** | The combination of [IAG token](#iag-tokens) [rewards](#rewards) and ADA [fees](#fees) earned by [node](#nodes) [operators](#operators) and [delegators](#delegators) based on [node](#nodes) performance. |
| <a id="fantasy-brawl-product"></a>**Fantasy Brawl** *(product)* | A unique sports fantasy league experience built using Iagon [Storage](#storage-product) and [Compute](#compute-product). |
| <a id="fees"></a>**Fees** | Monthly ADA Token earnings for [node](#nodes) [operators](#operators) and [delegators](#delegators) based on [node](#nodes) performance. These ADA Tokens are earned from [subscriptions](#subscriptions). |
| <a id="healthsafe-product"></a>**HealthSafe** *(product)* | A decentralized digital health portal designed to securely store and manage healthcare records, journals, and information. |
| <a id="iag-tokens"></a>**IAG Token**(s) | The native token of the Iagon protocol, minted on the Cardano blockchain with the ticker "[IAG](https://www.taptools.io/charts/token/iag)", used for staking towards resource commitments and to earn [rewards](#rewards). |
| <a id="launch"></a>**Launch** | Initiate a new [node](#nodes) on the Iagon network. |
| <a id="ledgerflow-product"></a>**LedgerFlow** *(product)* | A multifaceted financial platform that includes both individual and multisignature wallet management, bill issuance and payments, as well as tax tracking. |
| <a id="margin"></a>**Margin** | The percentage of the [delegator](#delegators)'s [earnings](#earnings) pool that the [node](#nodes) [operator](#operators) receives as a service fee, in addition to the [operator](#operators)'s own [earnings](#earnings). Updating a [node](#nodes)'s [margin](#margin) takes 2 [epochs](#epoch) (10 days) to take effect. |
| <a id="migrate"></a>**Migrate** | The act of changing the host system of a [node](#nodes) and repopulating the data held by that [node](#nodes) on the new host system. |
| <a id="network-explorer"></a>**Network Explorer** | A decentralized network of interconnected [nodes](#nodes) that process backend tasks for Iagon's [Storage](#storage-product) and [Compute](#compute-product) networks, including file distribution and data availability logging. |
| <a id="nodes"></a>**Node**(s) | An application that makes the host system's resources available on the Iagon network; or processes tasks for the Iagon network. |
| <a id="operators"></a>**Operator**(s) | A person or party that hosts and manages a [node](#nodes). |
| <a id="pledge"></a>**Pledge**  | The amount of a [node](#nodes)'s [stake](#stake) that is contributed by the [operator](#operators). |
| <a id="position"></a>(Delegated) **Position**  | An agreement that entitles a defined share of a [node](#nodes)'s [Earnings](#earnings) so long as [IAG tokens](#iag-tokens) are [delegated](#delegate-delegated-delegation) to that [node](#nodes). |
| <a id="quick-delegate-delegation"></a>**Quick Delegate/Delegation** | Quickly aggregate the best [nodes](#nodes) according to search filters and [delegate](#delegate-delegated-delegation) [IAG tokens](#iag-tokens) to them in order of potential profitability. |
| <a id="requesting-delegation"></a>**Request**(ing)(ed) **Delegation** | The act of requesting [IAG tokens](#iag-tokens) from [delegators](#delegators) via Iagon's [Staking Platform](#staking-platform-product) for a [node](#nodes) to increase its total [stake](#stake) and thus [commit](#commit-commitment-committed) more resources. |
| <a id="resize"></a>**Resize** | The action of increasing a [node](#nodes)'s [commitment](#commit-commitment-committed). |
| <a id="return-on-delegation"></a>**Return on Delegation** (ROD) | The annualized returns of [delegated](#delegate-delegated-delegation) [IAG tokens](#iag-tokens) as a percentage. |
| <a id="return-on-stake"></a>**Return on Stake** (ROS) | The annualized returns of [staked](#stake) [IAG tokens](#iag-tokens) as a percentage. |
| <a id="rewards"></a>**Rewards** | [Epochly](#epoch) [IAG token](#iag-tokens) [earnings](#earnings) for [node](#nodes) [operators](#operators) and [delegators](#delegators) based on [node](#nodes) performance. These [IAG tokens](#iag-tokens) are designated in Iagon's tokenomics. |
| <a id="sharding"></a>**Sharding** | A method for splitting and distributing files across multiple [Storage](#storage-product) [nodes](#nodes). |
| <a id="sme"></a>**SME** | Small and medium Enterprise. |
| <a id="stake"></a>**Stake**(d) | The [IAG token](#iag-tokens) deposit required to operate a node. |
| <a id="staking-platform-product"></a>**Staking** (Platform) *(product)* | A platform on the Iagon website that connects [node](#nodes) [operators](#operators) with [delegators](#delegators) to deposit [delegation](#delegate-delegated-delegation) to [nodes](#nodes) that require more [stake](#stake) to increase their [commitment](#commit-commitment-committed). |
| <a id="storage-product"></a>**Storage** *(product)* | A stream of the Iagon network that specifically hosts files for any given timeline distributed among [nodes](#nodes). |
| <a id="subscribers"></a>**Subscriber**(s) | A person or party that pays a [subscription](#subscriptions) to use Iagon services. |
| <a id="subscriptions"></a>**Subscription**(s) | An agreement to utilize resources on the Iagon network for an agreed-upon monthly or annual payment cost. |
| <a id="subnetwork"></a>**Subnetwork** | A subset of [nodes](#nodes) catered to specific [subscriber](#subscribers) needs, such as [nodes](#nodes) only in a specific region; or having a specific minimum bandwidth. |
| <a id="swap"></a>**Swap** | Quickly exchange ADA for [IAG tokens](#iag-tokens) that are already [delegated](#delegate-delegated-delegation), or [delegated](#delegate-delegated-delegation) [IAG tokens](#iag-tokens) for ADA. |
| <a id="transfer-product"></a>**Transfer** *(product)* | A file sharing platform for [storage](#storage-product) [subscribers](#subscribers) to quickly share files with expiring links that can be encrypted with a password. |
| <a id="withdraw"></a>**Withdraw** | Remove [IAG tokens](#iag-tokens) from an active [delegated](#delegate-delegated-delegation), ending the [earnings](#earnings) sharing agreement. |
