# Storage Subscriptions

## Overview

The prices and tiers here are based on the per GB storage price. Additional to storage size, the user is able to access other services offered by Iagon on the basis of tier.

```
Price per tier = Cost per GB * total GB offered + charges of services offered on each tiers

Per GB dollar value of tokens to be held = 0.2USD
```
