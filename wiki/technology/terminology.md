# Technical terminology

The docs define their terms in [Terminology](https://docs.iagon.com/overview/terminology). This page keeps the terms marketing meets most and says how to use them in copy. Where the brand [Vocabulary](../brand/voice/vocabulary.md) has a rule, the brand rule wins in marketing copy. The docs meaning stays the reference.

## Network roles

| Term | Docs meaning | In marketing copy |
|---|---|---|
| **Node** | Application that makes a host system's resources available to the network | "Node" for operator audiences. "Independent storage providers" or "the network" for business audiences. |
| **Operator** | Person or party that hosts and manages a node | "Node operator". Never "miner". |
| **Delegator** | Party that adds IAG to a node's stake for a share of earnings | Token holder audience only. |
| **Subscriber** | Party that pays a subscription | "Customer" in business copy. |

## Economics

| Term | Docs meaning | In marketing copy |
|---|---|---|
| **Stake / Pledge** | IAG deposit required to operate a node. Pledge is the operator's own part | Explain once: "IAG locked to activate capacity". |
| **Commit / Commitment** | Resources allocated to the network | "Committed capacity". |
| **Margin** | Operator's percentage of delegators' earnings. Changes take 2 epochs | Operator and delegator audiences only. |
| **Fees** | Monthly ADA from subscriptions | "Fees" are ADA from customers. Keep separate from rewards. |
| **Rewards** | Epochly IAG from the tokenomics schedule | "Rewards" are IAG incentives. Never "yield" or "returns" in public copy. |
| **Earnings** | Fees plus rewards | |
| **ROS / ROD** | Annualized returns on stake / on delegation, as a percentage | Do not use in marketing. |
| **Position** | Right to a share of a node's earnings while IAG stays delegated. Can be sold | Staking Platform context only. |
| **Epoch** | 5 days, aligned with Cardano | Spell out "every 5 days" for non-crypto readers. |

## Products and layers

| Term | Docs meaning | In marketing copy |
|---|---|---|
| **Storage** | The network stream that hosts files across nodes | "Iagon Storage". |
| **Compute** | The stream that hosts apps and tasks | "Iagon Compute". Check status first ([Compute](compute.md)). |
| **Subnetwork** | Subset of nodes for specific needs, such as a region or minimum bandwidth | Strong enterprise term: "data stays in the region you choose". |
| **Sharding** | Splitting and distributing files across storage nodes | Explain the benefit, not the mechanism: "no single provider holds your file". |
| **Secure Lake, Rubato, Fermato, Adagio** | Internal names of the storage, marketplace, subscription and rewards layers | Not in business copy. Allowed in developer and architecture content, with one line of explanation. |
| **Cyclone / Cyclone OS** | Iagon-built node server and its Linux distribution | Product names, capitalized. |
| **Iagonauts** | Storage tiers for IAG holders. Also the mascot name | Community copy only. |
