# Formats

Approved graphic formats: exact specs for recurring visuals. Each format follows [colors and typography](../colors-typography.md), the [canvas sizes and canvas type scale](../canvases.md) and the [logo rules](../logo.md), plus its own format-specific rules.

The design system comes first ([decision 0014](../../../../decisions/0014-design-system-first.md)). A format page can add rules but never relax the design system without an approved exception written on the page with the reason. A reference layout is input, not a spec.

Format rules apply only to that format. For example, the Industry Insights ban on spheres and globes doesn't apply to the "Total Earned By Nodes" post.
