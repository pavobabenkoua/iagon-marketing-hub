# Partnership pipeline

Internal register of every partnership and opportunity, with its real stage. **Private: never exposed through the API and never quoted in external material.**

A name moves to the [Proof Library](../brand/messaging/proof-library.md) only when there is written clearance and agreed wording ([Rule 1](../brand/messaging/proof-library.md#rule-1--enterprise-deployments)).

## Stages

| Stage | Meaning | External mention |
|---|---|---|
| **Concept** | An idea or a conversation. Nothing agreed | Never |
| **Pilot** | Agreement in place, test environment | Only with written clearance, always called "pilot" |
| **Integration** | Technically connected and working | Only with written clearance |
| **Production** | Real use by the customer | Only with written clearance |
| **Closed** | Did not go ahead | Never. Kept for history only |

## Rules

- Update the stage here first. Every other page follows this register.
- A concept never appears in external material, not even unnamed ("a Fortune 500 company").
- A closed partnership is never mentioned externally.
- When a partner gets written clearance, add the agreed wording here and create the Proof Library entry.
