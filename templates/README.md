# Templates

Copy a template to start a new page. Replace every `<placeholder>` and `YYYY-MM-DD`, then set `status` when the page is ready.

| Template | For |
|---|---|
| [product.md](product.md) | A product in `wiki/products/` |
| [audience.md](audience.md) | A segment or persona in `wiki/audiences/` |
| [channel.md](channel.md) | A channel in `wiki/channels/` |
| [series.md](series.md) | A content series, saved as `wiki/series/<slug>/series.md`. Keep the sections for its type (decision 0008) |
| [post.md](post.md) | A post in a series (`wiki/series/<slug>/posts/NN-slug.md`) or a post outside series (`wiki/posts/YYYY-MM-DD-slug.md`). One post can go out on several channels |
| [campaign.md](campaign.md) | A campaign in `wiki/campaigns/YYYY-slug/` |
| [playbook.md](playbook.md) | A method in `wiki/playbooks/` |
| [decision.md](decision.md) | A decision record in `decisions/` |
| [fact.yaml](fact.yaml) | One entry in `wiki/data/facts.yaml` |
